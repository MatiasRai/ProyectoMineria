Proyecto de predicción del riesgo de suicidio
Este proyecto se centra en el desarrollo de un modelo predictivo para evaluar el riesgo de suicidio utilizando un conjunto de datos de salud mental. El objetivo es proporcionar herramientas analíticas avanzadas que ayuden a identificar patrones y factores de riesgo asociados con las conductas suicidas. Se utilizará la metodología CRISP-DM y técnicas de aprendizaje automático para crear un sistema que ayude a todas las personas en la detección temprana y la prevención del suicidio, mejorando así la calidad y la eficacia de las intervenciones clínicas o las consultas psicológicas. Este proyecto es especialmente relevante dado el importante impacto que el suicidio tiene en la salud pública y el bienestar social. Su objetivo es contribuir sustancialmente a los esfuerzos globales para reducir la incidencia del suicidio, proporcionando recursos valiosos a los profesionales de la salud mental y a la comunidad en general. Preguntas clave: ¿Qué factores se asocian con un mayor riesgo de suicidio? ¿Qué medidas se tomarán en función de las predicciones?

Instalación de dependencias:
Declare cualquier dependencia en requirements.txt para la instalación de pip.

Para instalarlos, ejecute:

pip install -r requirements.txt
Cómo ejecutar un pipeline:
Puede ejecutar su proyecto Kedro con:

kedro run
Cómo ejecutar Jupyter Notebook:
Para usar cuadernos Jupyter en su proyecto Kedro, necesita instalar Jupyter:

pip install jupyter
Después de instalar Jupyter, puedes iniciar un servidor de notebook local:

kedro jupyter notebook
Otra opción es utilizar IPython
Y si quieres ejecutar una sesión IPython:

kedro ipython
